# Розгортання автоматичного ML-імпорту

1. Збережіть свій `.env` (у ZIP його немає).
2. Замініть файли проєкту вмістом архіву.
3. Виконайте:

```bash
npm install
npm test
git add .
git commit -m "Add automatic 1C ML import"
git push origin main
```

4. Дочекайтеся статусу **Live** на Render.
5. Надішліть один сирий `ML.xlsx` із 1С у канал.

Очікувана відповідь бота:

```text
✅ ML.xlsx імпортовано
Період: 2026-07-27–2026-08-02
Рядків: 269
2026-07: weekly, 2026-08: weekly
```

Якщо файл уже імпортовувався, бот повідомить про збіг SHA-256 і не запише його повторно. Якщо назва регіону, відділу або працівника відсутня в довідниках PostgreSQL, імпорт повністю відкотиться і бот покаже точну назву та рядок.

Автоімпорт `PlanMin` і `PlanBNAC` у цій версії ще не ввімкнений.
