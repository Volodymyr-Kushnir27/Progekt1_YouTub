# Імпорт усіх даних за 2026 рік

У папці `data` мають бути файли `main-2026.xlsx`, `апрель.xlsx`, `май.xlsx` і `июнь.xlsx`.

## 1. Перевірка без запису в PostgreSQL

```bash
npm install
npm run import:all:dry
```

Команда читає всі чотири файли, перевіряє структуру, не допускає подвійного підрахунку продажу точки при двох продавцях і створює службовий `data/import-all.generated.xlsx`.

## 2. Перевірка SQL-схеми

```bash
npm run import:schema
```

Потрібен коректний `DATABASE_URL` у локальному `.env`.

## 3. Запис усіх даних у PostgreSQL

```bash
npm run import:all:db
```

Імпорт транзакційний. Місяці у файлах замінюються цілком, тому повторний запуск не створює дублікати. Старі працівники й відділи, яких немає в липневому активному довіднику, створюються як неактивні історичні записи.

## 4. Контроль після імпорту

```bash
npm run import:verify
```

Очікувана перша дата продажів — `2026-04-01`, остання в поточному файлі — `2026-07-26`.
