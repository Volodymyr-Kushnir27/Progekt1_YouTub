# Імпорт Excel у PostgreSQL

Спочатку перевірте Excel без запису:

```bash
npm run import:dry -- "./data/main-2026.xlsx"
```

Перевірте сумісність схеми БД:

```bash
npm run import:schema
```

Щотижневий імпорт додає нові рядки та оновлює наявні (`UPSERT`):

```bash
npm run import:db -- "./data/main-2026.xlsx" --mode weekly
```

Імпорт виконується пакетами по 200 рядків і показує прогрес. За потреби розмір пакета можна зменшити:

```bash
npm run import:db -- "./data/main-2026.xlsx" --mode weekly --batch-size 100
```

Фінальний місячний імпорт спочатку очищає місяці, представлені у файлі, а потім записує їх заново в одній транзакції:

```bash
npm run import:db -- "./data/main-2026.xlsx" --mode monthly
```

Якщо будь-який рядок або структура БД не пройде перевірку, виконується `ROLLBACK`.

Підсумкові рядки `Тип_об’єкта = Загалом` / `ИТОГО` з аркуша
`ПЛАНИ_ВІДДІЛІВ` імпортер пропускає автоматично. У базі підсумки мають
обчислюватися з рядків відділів і регіонів, а не зберігатися повторно.
