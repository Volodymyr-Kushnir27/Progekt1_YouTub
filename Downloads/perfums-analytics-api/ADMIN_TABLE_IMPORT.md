# Адмін-таблиця: Telegram → БД → GPT

## Що імпортується

- регіон, місяць, результат минулого року та ціль регіону;
- продавець або відділ, ціль і план дій;
- лише текст у колонках **«Що виконано за планом»**.

Колонки **«Дійсний результат (%)»** та **«Очікуваний результат (%)»** з Excel навмисно не імпортуються. API рахує факт із БД, а прогноз — окремим контрольованим методом.

## Як завантажувати

1. Не змінюйте назви службових клітинок і трьох секцій шаблону.
2. Назва файла має містити `Адмін таблиця`, наприклад `Адмін таблиця (Таїрова).xlsx`.
3. Надішліть XLSX у Telegram-канал, підключений до бота.
4. Бот поверне місяць, регіон, кількість об'єктів і кількість заповнених тижневих звітів.

Повторне надсилання того самого файла не дублює дані. Новіша версія оновлює цілі, план дій та непорожні поля «Що виконано». Порожня клітинка не стирає раніше завантажений текст.

## Довідники

Адмін-таблиця не створює працівників або відділи, бо скорочене ім'я може бути неоднозначним. Нові працівники й відділи спочатку створюються з оперативних ML/Plan/Payroll-звітів. Якщо об'єкт не знайдено однозначно, бот відхиляє файл і називає проблемний рядок.

## Розгортання

Після завантаження коду на Render виконайте redeploy. Потім у GPT Actions замініть OpenAPI-схему файлом `openapi-gpt-actions-fixed.yaml`, а інструкцію асистента — вмістом `GPT_INSTRUCTIONS.md`.
